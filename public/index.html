CONNECTION GUIDE
接入指南


选择客户端支持的 API 标准，模型调用 ID 均使用「前缀/模型 ID」。








Anthropic Messages 标准
  1. 客户端选择 Anthropic 兼容协议，Base URL 填服务根地址，不加 /v1。
  2. API Key 填上方网关密钥，模型选择已有的「前缀/模型 ID」。
  3. 请求使用 x-api-key 和 anthropic-version: 2023-06-01；也支持 Bearer 认证。



支持文本、图片、工具调用、流式 Messages 和 thinking 参数；历史思考块不转换为回答正文，服务端工具、提示缓存控制和 token 计数接口暂不支持。






OpenAI 标准
  1. 客户端选择 OpenAI 兼容协议，Base URL 使用包含 /v1 的地址。
  2. API Key 填上方网关密钥，模型选择已有的「前缀/模型 ID」。
  3. Codex 使用 Responses；其他客户端可按能力选择 Chat Completions 或 Responses。



支持文本、图片与客户端工具。远程 Codex 使用完整历史和 store=false，不支持 previous_response_id 持久会话。




模型能力取决于上游。远程 Codex 的输出 token 预算为生成提示，不是硬性截断。
